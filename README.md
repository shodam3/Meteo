# Meteostanice

Webová aplikace pro zobrazení dat z domácí meteostanice (Garni 940) uložených na Weather Underground.

- grafy čárové i sloupcové, měřítko den / týden / měsíc / rok, posun dopředu a dozadu
- u sloupců přepínání maximum / minimum / průměr
- souhrn za zvolené období a srovnání dvou období v jednom grafu
- data se ukládají v telefonu a volitelně do soukromého repozitáře na GitHubu

Klíče k Weather Underground a GitHubu se zadávají v aplikaci a zůstávají jen v prohlížeči. V tomto repozitáři nejsou žádná data ani klíče.
